# 本项目 MATLAB 仿真：先看什么、怎样复现

本目录对应当前 F28P55X Buck/Boost 实验代码。负载按作者实物使用的外接 **5Ω 滑动变阻器**设置；输入电压、电感等未确认项是示例假设。这里使用离散 PI＋连续平均功率级，不需要 Simulink 或 Simscape；已在 MATLAB R2023b 运行。

## 阅读顺序

1. 先读根目录 README 的模式表，区分单电流环、双环、开环。
2. 看 [buck_current.png](results/buck_current.png)：目标 0.8A，经5Ω负载，稳态输出应接近4V。单电流环没有输出电压给定。
3. 看 [buck_dual.png](results/buck_dual.png)：目标6V，电压外环给出所需电流约1.2A，电流内环再调占空比。
4. 看 [boost_current.png](results/boost_current.png)、[boost_dual.png](results/boost_dual.png)：前者控制的是低压输入支路电流，不能拿输入电流直接乘输出端5Ω去算输出电压。
5. 看 [buck_mode_change.png](results/buck_mode_change.png)、[boost_mode_change.png](results/boost_mode_change.png)：12秒请求电流环→双环，停机、清积分，等待模式确认后重新给目标。这里没有带载 Buck/Boost 换向实验。
6. 最后用 [summary.csv](results/summary.csv)核对稳态结果，再看两张 open 图与 buck_voltage 对照图。

每张图从上到下：

- 输出电压与电压目标。电流/开环模式中虚线为0，表示没有电压给定，不表示期望输出为0。
- 端口反馈电流、电感电流、电流参考。双环的电流参考由电压PI产生，单电流环由人设定；开环/单电压环不使用电流参考，虚线为0。
- 左轴为主动开关占空比（%），右轴为使能（0/1）。Boost画的是低侧储能占空比，代码给 IR2104 IN 的高电平占空比取其补数。
- 控制模式用文字标识：Current单电流环、Dual双环、Open开环、Voltage单电压环、Waiting切换等待（代码值255）。

## 一次运行

MATLAB切换到仓库根目录后：

```matlab
addpath('simulation');
run_project_simulation;
```

从其他目录调用时先把 simulation 的完整路径加入 path。入口以自身文件位置解析路径，输出总是写入 `simulation/results/`。

共9个场景：四种主要闭环、两种开环、Buck单电压环、两个同方向模式切换。每个场景40秒，0.2秒给目标；切换例在12秒改变请求，25ms后人工重新给目标。结果图保留控制响应的真实时间尺度，没有把慢响应裁掉。

results根目录保留 PNG 和 summary.csv 供阅读；data子目录中，CSV 为100Hz抽样数据，MAT为1kHz日志和参数，控制计算仍为20kHz。`summary.csv`给出末1秒均值、全控制步内的电感电流峰值、有限性检查，以及闭环最终绝对误差（电流模式A，其余闭环V；开环NaN）。PNG与summary.csv随源码保留，其余可重新生成。

脚本自动检查所有数据为有限数、占空比不越界；示例闭环末1秒的平均电流误差要求<0.02A，平均电压误差要求<0.05V。这是当前假设下的数值自检，不是实物验收指标；没有执行完整固件保护模型。

## 功率级模型与测量位置

记 iL 为电感电流，vL 为低压端电压，vH为高压端电压，d为主动开关占空比。

Buck用理想高压电源供电，负载接低压端：

```text
L · diL/dt = d · Vhigh - vL - rL · iL
Clow · dvL/dt = iL - vL/Rload
I反馈 = vL/Rload
```

Boost由低压源 E 经等效电阻 Rs 供电，负载接高压端：

```text
L · diL/dt = vL - (1-d) · vH - rL · iL
Clow · dvL/dt = (E-vL)/Rs - iL
Chigh · dvH/dt = (1-d) · iL - vH/Rload
I反馈 = (E-vL)/Rs
```

**R4测端口支路，电容电流不必经过R4，不能把反馈直接替换成iL。** 稳态电容平均电流接近0，二者可接近；暂态可以明显不同。Buck这里用电阻负载替代电池；Boost用带阻抗的低压电源。它们是本次电阻实验的等效场景，不是完整电池模型。

积分使用50µs步长的RK4。Boost及关断Buck采用理想二极管零电流边界近似；正常使能的同步Buck允许反向iL。Boost关断PWM后仍可经电感和体二极管路径向输出供电，输出不必归零，停机不等于电气隔离。关断时的体二极管换流、掉电/再生能量及器件非理想行为未完整建立，因此模式切换图只用于理解停机与重新给定流程。

## 控制器怎样对应代码

- 全部误差用目标减反馈。Boost的端口方向先归一化成正的工作电流。
- 固件电流PI输出单位是占空比百分点，MATLAB转成0～1，占空比增益除100；Ki在每步再乘50µs。
- 双环电压PI输出A，Kp/Ki保持A/V、A/(V·s)，仅Ki乘周期。
- Buck单电压PI与电流PI一样使用占空比百分点单位。
- 条件积分与 `pid.c` 相同：到上限且误差仍向上时停积，到下限且误差仍向下时停积，积分本身也限幅。
- Buck占空比0～95%，Boost5～60%；开环示例20%。比较寄存器按3750计数量化，Boost使用互补映射。
- 含12位ADC量化示例，未建模实测噪声、校准误差、4路SOC时序与固件软件均值全部细节。MATLAB双精度计算，DSP控制为float32，因此不是逐位相同的执行。

## 本目录能说明与不能说明的内容

可以观察电流/电压目标的动态跟随、PI限幅和模式重新启动，也可以替换参数探索敏感性。当前模型没有每个开关周期波形，**不能从图中读取真实电感纹波，更不能据此证明转换效率**。未建模 MOSFET 开关损耗、驱动死区、自举供电、磁芯损耗、PCB寄生、温升及完整故障保护。

后续需要纹波/损耗时应增加开关级模型和器件参数；需要匹配实物响应时，先补齐实际L/C、供电阻抗、采样滤波和输入条件，再做对比测量。改变硬件或PI后需重跑，不能继续把旧PNG当作新结果。
